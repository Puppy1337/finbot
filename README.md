# FinBot — личный финансовый аналитик в Telegram

Бот, которому можно писать, наговаривать голосом или присылать скриншоты из банка. Он записывает траты и доходы, считает бюджеты и цели, рисует отчёты и — через Claude (Anthropic) — коротко советует, как сохранить деньги.

## Что умеет

| Вы делаете | Бот делает |
|---|---|
| «кофе 4.5», «такси 12 евро вчера», «зарплата 3000» | Записывает операцию, пересчитывает в базовую валюту, даёт короткий совет |
| Голосовое сообщение | Расшифровывает и обрабатывает как текст |
| Скриншот из банковского приложения | Вытаскивает все операции, пропускает уже записанные |
| PDF-выписка из банка (до 20 МБ) | Разбирает все операции за период; любой другой финансовый PDF (договор, счёт, чек) кратко пересказывает и комментирует |
| «сколько я потратил на еду?», «на чём сэкономить?» | Отвечает с опорой на ваши реальные цифры |
| `/budget Еда 300` | Ставит лимит и предупреждает на 80 % и 100 % |
| `/goal Отпуск 2000 2026-12-31`, `/save Отпуск 100` | Ведёт цели накопления и считает, сколько откладывать в месяц |
| `/today` `/week` `/month` | Сводка + картинка-график по категориям и дням |
| `/months` | Сравнение последних месяцев по категориям (точные суммы из базы) |
| `/advice` | Развёрнутый разбор месяца и план экономии |
| `/rules Отвечай абзацами с эмодзи…` | Ваши постоянные правила — бот учитывает их в каждом ответе |
| `/remind 21:00` | Ежедневное напоминание; по понедельникам — отчёт за неделю |
| `/undo`, кнопка «Отменить» | Исправить ошибку распознавания |
| `/export` | CSV со всеми данными (открывается в Excel) |

Бот «держит в уме» контекст: при каждом ответе Claude получает итоги месяца, категории, бюджеты, цели, сравнение с прошлым месяцем и последние операции.

## Как это устроено

```
 Telegram  ──►  бот (Python, ваш сервер)  ──►  Claude API (Anthropic) — «мозг»: понимает текст и скриншоты, советует
                     │                    ──►  Whisper API (OpenAI/Groq) — голос → текст
                     │                    ──►  frankfurter.app — курсы валют (бесплатно, без ключа)
                     ▼
               SQLite (data/finbot.db) — все ваши данные лежат только у вас на сервере
```

Файлы:

```
finbot/
  bot.py        команды, обработка сообщений, напоминания
  claude.py     обращение к Claude API (извлечение операций + советы)
  telegram.py   клиент Telegram Bot API
  stt.py        распознавание голоса
  reports.py    отчёты, контекст для Claude, графики
  rates.py      курсы валют
  db.py         база данных SQLite
  config.py     настройки из .env
main.py         запуск
tests/          сквозной тест без сети: python -m tests.test_flow
```

# Полная инструкция по запуску (для новичка)

Вам понадобится ~40 минут и банковская карта для оплаты API (Claude берёт деньги за использование, примерно $1–3 в месяц при активном личном использовании).

## Шаг 1. Создать бота в Telegram (2 минуты)

1. Откройте Telegram, найдите **@BotFather** (с галочкой), нажмите Start.
2. Отправьте команду `/newbot`.
3. Введите имя бота (как будет отображаться), например `Мои финансы`.
4. Введите username — должен заканчиваться на `bot`, например `anton_finance_bot`.
5. BotFather пришлёт **токен** вида `7123456789:AAF...` — скопируйте, это пароль бота, никому не показывайте.
6. Необязательно, но приятно: `/setuserpic` — аватар, `/setdescription` — описание.

## Шаг 2. Получить ключ Claude API (5 минут)

1. Зайдите на **https://console.anthropic.com** и зарегистрируйтесь.
2. Слева **Billing** → добавьте карту и пополните баланс (достаточно $5).
3. Слева **API Keys** → **Create Key** → назовите `finbot` → скопируйте ключ `sk-ant-...` (показывается один раз).

## Шаг 3. Ключ для распознавания голоса (5 минут, можно пропустить)

Без этого шага бот будет работать, но голосовые сообщения попросит написать текстом.

**Вариант А — Groq (бесплатно):** https://console.groq.com → API Keys → Create. В `.env` укажите:
```
STT_API_KEY=gsk_...
STT_BASE_URL=https://api.groq.com/openai/v1
STT_MODEL=whisper-large-v3-turbo
```

**Вариант Б — OpenAI (платно, копейки):** https://platform.openai.com → API keys. В `.env`:
```
STT_API_KEY=sk-...
```
(остальные строки STT оставьте по умолчанию).

## Шаг 4. Узнать свой Telegram ID (1 минута)

Напишите боту **@userinfobot** любое сообщение — он ответит числом `Id: 123456789`. Это нужно, чтобы вашим ботом (и вашими финансами) не мог пользоваться никто, кроме вас.

## Шаг 5. Арендовать сервер (10 минут)

Подойдёт самый дешёвый VPS (виртуальный сервер) с Ubuntu: Hetzner (~€4/мес), DigitalOcean, Vultr, любой местный хостер. При создании выберите:

- образ **Ubuntu 24.04**,
- минимальный тариф (1 CPU, 1–2 ГБ RAM),
- способ входа: **пароль** (проще) или SSH-ключ.

После создания у вас будет **IP-адрес** сервера и **пароль root**.

**Как подключиться к серверу:**
- Windows: откройте PowerShell (Пуск → введите `PowerShell`), Mac/Linux: откройте «Терминал».
- Введите: `ssh root@ВАШ_IP` → Enter → на вопрос про fingerprint ответьте `yes` → введите пароль (при вводе символы не отображаются — это нормально).

Вы внутри сервера. Дальнейшие команды вводятся здесь.

## Шаг 6. Установить Docker на сервер (5 минут)

Скопируйте и выполните по одной строке:

```bash
apt update && apt upgrade -y
curl -fsSL https://get.docker.com | sh
docker --version
```

Последняя команда должна вывести версию Docker — значит всё установилось.

## Шаг 7. Загрузить бота на сервер (5 минут)

**Способ 1 — через архив.** На своём компьютере откройте новое окно терминала (не закрывая сервер) и выполните из папки, где лежит `finbot.zip`:

```bash
scp finbot.zip root@ВАШ_IP:/root/
```

Затем на сервере:

```bash
apt install -y unzip
cd /root && unzip -o finbot.zip && cd finbot
```

**Способ 2 — через GitHub** (если положите проект в приватный репозиторий): `git clone https://github.com/вы/finbot.git && cd finbot`.

## Шаг 8. Настроить .env (3 минуты)

```bash
cp .env.example .env
nano .env
```

Откроется редактор. Впишите свои значения:

```
TELEGRAM_BOT_TOKEN=7123456789:AAF...     ← из шага 1
ANTHROPIC_API_KEY=sk-ant-...             ← из шага 2
ALLOWED_USER_IDS=123456789               ← из шага 4
STT_API_KEY=gsk_...                       ← из шага 3 (если делали)
BASE_CURRENCY=USD                         ← или EUR
TIMEZONE=Europe/Kyiv
```

Сохранить и выйти из nano: `Ctrl+O`, `Enter`, затем `Ctrl+X`.

## Шаг 9. Запустить (2 минуты)

```bash
docker compose up -d --build
```

Первый запуск скачает образ и соберёт контейнер (1–2 минуты). Проверьте, что бот жив:

```bash
docker compose logs -f
```

Должна появиться строка `Бот запущен, ожидаю сообщения…`. Выйти из просмотра логов: `Ctrl+C` (бот продолжит работать).

Откройте своего бота в Telegram, нажмите **Start** и напишите «кофе 4». Готово 🎉

Бот перезапускается сам после перезагрузки сервера (`restart: unless-stopped` в docker-compose.yml).

## Полезные команды на сервере

| Что нужно | Команда (из папки `/root/finbot`) |
|---|---|
| Посмотреть логи | `docker compose logs -f --tail 100` |
| Перезапустить | `docker compose restart` |
| Остановить | `docker compose down` |
| Обновить после изменения кода или .env | `docker compose up -d --build` |
| Бэкап базы данных | `cp data/finbot.db ~/finbot-backup-$(date +%F).db` |
| Скачать бэкап на свой компьютер (с компьютера) | `scp root@ВАШ_IP:/root/finbot/data/finbot.db ./` |

Все ваши данные — один файл `data/finbot.db`. Периодически копируйте его.

## Запуск без Docker (альтернатива)

```bash
apt install -y python3 python3-venv
cd /root/finbot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Чтобы бот работал постоянно, создайте службу systemd:

```bash
cat > /etc/systemd/system/finbot.service <<'EOF'
[Unit]
Description=FinBot Telegram
After=network.target
[Service]
WorkingDirectory=/root/finbot
ExecStart=/root/finbot/.venv/bin/python main.py
Restart=always
RestartSec=5
[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload && systemctl enable --now finbot
journalctl -u finbot -f     # логи
```

## Запуск на своём компьютере (для пробы)

Нужен Python 3.11+. В папке проекта: `pip install -r requirements.txt`, заполните `.env`, затем `python main.py`. Бот работает, пока окно открыто.

## Частые проблемы

- **`Не задан TELEGRAM_BOT_TOKEN`** — файл `.env` не создан или лежит не в папке проекта.
- **`Доступ закрыт. Ваш ID: …`** — впишите этот ID в `ALLOWED_USER_IDS` и выполните `docker compose up -d --build`.
- **`Claude API 401`** — неверный ключ Anthropic. **`Claude API 400 … credit balance`** — пополните баланс в консоли Anthropic.
- **`Claude API 404 model not found`** — модель переименована; посмотрите актуальные на https://platform.claude.com/docs/en/models/overview и поменяйте `ANTHROPIC_MODEL` в `.env`.
- **Голосовые не распознаются** — проверьте `STT_API_KEY` и `STT_BASE_URL`.
- **Бот молчит** — `docker compose logs -f`, там будет причина. Убедитесь, что на сервере есть доступ в интернет и нигде не запущена вторая копия бота с тем же токеном (Telegram отдаёт сообщения только одной).

## Стоимость

- VPS: €4–6 в месяц.
- Claude: ~$0.01–0.03 за сообщение (скриншоты дороже текста). При 10–20 сообщениях в день — $1–3 в месяц. Модель можно сменить на более дешёвую в `.env` (`ANTHROPIC_MODEL`).
- Голос: Groq бесплатно; OpenAI Whisper ~$0.006 за минуту аудио.

## Приватность

Данные хранятся только в вашем SQLite на вашем сервере. Во внешние сервисы уходят: текст/картинка сообщения и сводка ваших трат (в Claude для анализа), аудио (в сервис распознавания). Ограничьте доступ через `ALLOWED_USER_IDS`.
